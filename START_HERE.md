# Start Here - Pizza Pie Parlor Team Handoff v2.5.0

This is an **upgrade** of the original v2.1.3 backend. The backend is
package v2.2.0; v2.5.0 is the handoff bundle revision.

For **Notepad**, open `START_HERE.txt` instead.

1. Extract the ZIP; open PowerShell in the folder with `package.json`.
2. Run:

   ```powershell
   $env:Path = "C:\Program Files\nodejs;$env:Path"
   npm.cmd ci
   npm.cmd test
   npm.cmd start
   ```
3. Open `http://127.0.0.1:3000/team-demo.html` locally.
4. See `UPGRADE_FROM_v2.1.3.txt` and `DESIGN_EDITING_GUIDE.txt`.

The original comprehensive backend README is retained at
`docs/history/README_BACKEND_v2.1.3.md`. This is a replaceable visual
demo, not production checkout or a group-approved final theme.
