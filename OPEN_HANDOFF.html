Pizza Pie Parlor — Team Handoff v2.5.0

Upgrade of the original v2.1.3 backend: Sprint 7.1 cart UI + Sprint 7.2 cart API. The retro space look is a replaceable reference.

1. Start the working demo

Extract the ZIP completely. Open PowerShell in the folder that contains package.json, then run:

npm.cmd ci
npm.cmd test
npm.cmd start

Open the LIVE Pizza Pie Parlor demo (server required)

Check the LIVE menu API (server required)

Both links use localhost and only work on the computer running the server. This HTML guide itself can be opened without Node.
