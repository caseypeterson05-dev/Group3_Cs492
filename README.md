The vision for this project is to generate a website that follows proper user interface (UX) design so that an average user will find the menus, controls, and various functions intuitive.  This will include making the site and its associated pages easy to navigate.  The website will clearly dictate the description as provided by the owners of the restaurant, display photos of the family-friendly atmosphere, have easy access to the menu, and allow easy viewing of the current promotional items and discounts as necessary.
