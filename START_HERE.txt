START HERE - PIZZA PIE PARLOR TEAM HANDOFF v2.5.0
==================================================
This is an upgrade of the original v2.1.3 backend, with a working 7.1
shopping cart UI and strengthened 7.2 cart API. The current backend
package version is 2.2.0. The space-themed design is temporary.

WINDOWS LAUNCH
1. Extract the entire ZIP and open the folder containing package.json.
2. Open PowerShell in this directory and run:

   $env:Path = "C:\Program Files\nodejs;$env:Path"
   npm.cmd ci
   npm.cmd test
   npm.cmd start

3. Open http://127.0.0.1:3000/team-demo.html in your browser.
4. To stop the server, press Ctrl+C.

IMPORTANT: The address works only on the same computer running Node.
Do not double-click public/team-demo.html to run the live site.
